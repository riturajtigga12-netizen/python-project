## 💻 Example

### Hello World

```python
print("Hello, World!")
```

### Taking Input

```python
name = input("Enter your name: ")
print("Hello", name)
```

### If-Else

```python
age = int(input("Enter your age: "))

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

### For Loop

```python
for i in range(1, 6):
    print(i)
```

### List

```python
numbers = [10, 20, 30, 40, 50]

print(numbers)
print(numbers[0])
```

```bash

```

## ▶️ How to Run

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd python-basics
```

3. Run a Python file:

```bash
python filename.py
```
